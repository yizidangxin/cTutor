ctutor：只管 VS Code 不管的那几件事

编辑器功能（补全、格式化、跳转、调试、Git）全部交给 VS Code，这里只有四样东西： 中文讲解、只讲一条、改完复检、等输入不超时。

总开关
关闭后 ctutor 完全不介入：不检查、不画波浪线、不提供修复与运行。
中文分层讲解
悬停报错行看五层讲解（结论 / 定位 / 原因 / 改法 / 知识点）；编辑器里那条 CodeLens 也来自这里。
只讲最关键的一条
一次报 30 条时只画 1 条波浪线——后面 29 条几乎都是它引起的。关掉就全部显示。
自己画波浪线
用 ctutor 的诊断（中文结论）替代编译器原文。若同时开了 C/C++ 扩展的报错高亮，会出现两套，建议只留一边。
改一下（修复并复检）
缺分号、全角标点这类有确定性修法的错误，改完**重新编译验证**通过才写进文件；没通过就不动你的代码。
运行（等输入不计时）
在 VS Code 终端里运行当前文件；程序等 scanf 的时候不计超时，死循环可以一键停止。
AI 兜底讲解
默认关闭。只有本地知识库没收录的错误才需要它，且要自己配 DeepSeek 密钥；本地命中时不会联网、不花钱。

把光标放到报错行，或点编辑器里的「ctutor：这一条错在讲什么」。
